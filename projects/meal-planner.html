Meal Muse

Helps users plan daily meals with a randomized list.

Live Site → View on GitHub →

Overview

Meal Muse helps users plan their daily meals by generating a randomized list of meals based on their preferences and dietary restrictions.

Features

  • Randomize meals for the entire week
  • Save weeks for future reference
  • Save and edit favorite meals

Tech Stack

  • HTML — Basic structure
  • CSS — Styling and layout
  • Vanilla JavaScript — Interactivity and functionality

Challenges & Learnings

What was tricky:

I realized that the most basic MVP version of this app was a simple enough concept to build, but as soon as the MVP was live I realized that there were so many more features that could be added to make the app more useful and user-friendly.

What I learned:

I learned that it's important to focus on the core functionality of an app before adding additional features, as it can be easy to get carried away with ideas and lose sight of the original goal.

What I'd do differently:

If I could start over again, I'd make sure I had a clear road map for the MVP and the additional features I wanted to add for future states. That way I could plan the blueprints to be able to scale the app more efficiently.
